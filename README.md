# Bio-Data - Aditya Ankur

A beautiful, modern, and responsive bio-data website with an elegant autumn theme.

## Features

- Simple one-page marriage biodata (A4), easy to read
- Hindi + English section headings
- **Download PDF** button saves a one-page PDF (falls back to the browser's print / Save as PDF)
- Works on phone and desktop

## Local Development

Simply open `index.html` in your browser. No build process required!
