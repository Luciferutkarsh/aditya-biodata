# Bio-Data - Aditya Ankur

A beautiful, modern, and responsive bio-data website with an elegant autumn theme.

## Features

- 🍂 **Dynamic Autumn Theme** - 5 animated leaves roaming across the page
- 🌓 **Light/Dark Mode** - Toggle between Autumn Elegance and Midnight Sky themes
- 📱 **Fully Responsive** - Optimized for all devices (mobile, tablet, desktop)
- ✨ **Interactive Design** - Smooth hover effects and animations
- 🖨️ **Print-Friendly** - Clean layout for printing or saving as PDF

## Technologies Used

- HTML5
- CSS3 (with CSS Variables, Animations, Grid)
- Vanilla JavaScript
- Google Fonts (Playfair Display, Lato)

## Sections

- Personal Details
- Education & Career
- Hobbies & Interests
- Family Details & Background
- Contact Information
